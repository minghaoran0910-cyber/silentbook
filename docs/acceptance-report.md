## 3. 验收发现的 bug（已修 + 复验）

| # | 问题 | 根因 | 修复 | 复验 |
|---|------|------|------|------|
| 1 | R4S 浏览器登录永远跳回 | 生产 http + Secure Cookie 被拒收 | `COOKIE_SECURE` 可配置，R4S 设 false | cookie 会话 + UI 表单登录进首页 |
| 2 | PDF 导入 500 | routers 拆分漏改 `from .pdf_parser` | 改 `..pdf_parser` + 回归测试 | UI 上传招行 PDF 成功 3 条 |
| 3 | A 股同步全灭 | asset_sync 行内 `import re` 遮蔽 | 删除行内导入 | 600036 → 41.69 |
| 4 | 交行短信判成中国银行 | `bocom` 含子串 `boc` | source 精确优先 | 交通银行正确 + 回归测试 |

## 4. 已知限制（非 bug）

- AI 分析需自填 LLM Key（R4S `.env` 留空），否则仅占位提示。
- OpenClaw 绑定需网关注入 `OPENCLAW_GATEWAY_URL` 才可联调，当前为优雅降级。
- 历史遗留的个别错账行（如早期误判的 +¥50 收入）属测试数据，非代码问题。
- 全后端单测在 sqlite 下基线大面积红（auth/PG 方言等历史问题），与本次改动无关；
  本次新增 30+ 用例（webhook/账本/FX/迁移/PDF）全部绿。
